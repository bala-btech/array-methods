# ⚡ JavaScript Foundations: Arrays & Methods

A beginner-friendly collection of essential JavaScript logic, tracking fundamental control structures, mutating versus non-mutating methods, and iterative callback functions.

## 🚀 Solved Problems Reference

### 1) Element Adder — push()
An operation that appends one or more elements directly to the trailing end of an existing array, updating its structural bounds and returning the updated total length.

### 2) Tail Extractor — pop()
A destructive mutator method that isolates, extracts, and returns the final element of an array, permanently truncating the array length by an index of one.

### 3) Head Remover — shift()
A positional mutator that deletes the zeroth-index element from the front of an array, shifting all subsequent index values down by one position and returning the removed item.

### 4) Prefix Insert — unshift()
A high-priority insertion operation that injects one or more elements directly into the beginning of an array, pushing existing indices forward and returning the new length.

### 5) Data Transformer — map()
An iterative, non-mutating powerhouse that projects a specified callback function onto every individual element within a collection, returning a brand-new array of identical length containing the transformed values.

### 6) Conditional Filter — filter()
A structural selection engine that evaluates each item against a boolean testing condition, producing a clean, shallow copy containing only the elements that successfully validate as true.

### 7) Array Reducer — Accumulator Core
A complex processing function that iteratively marches through an array, passing each element along with a running total into a callback to compress the entire collection down to a single aggregate value.

### 8) First Fit Matcher — find()
A targeted lookup function that scans an array sequentially and immediately halts execution to return the exact value of the very first element that matches a given search criterion.

### 9) Existence Validator — includes()
A clean, logical checking utility that parses an array to verify if a specific target value exists within its contents, immediately returning a definitive true or false value.

### 10) In-Place Modifier — splice()
A versatile and destructive multi-tool capable of adding, removing, or replacing elements at any arbitrary index path within an array, altering the original source dataset directly.

### 11) Section Extractor — slice()
A non-destructive subset collector that extracts a specified range of elements between a starting index and an optional ending index, rendering them into an isolated, independent array fragment.
